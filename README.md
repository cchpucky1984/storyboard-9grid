# 九宮格分鏡板 · Storyboard 9-Grid

拍攝現場用嘅單檔分鏡工具：**把參考圖拖入九宮格 → 調整構圖 → 匯出成一張分鏡圖**。
零安裝、零依賴、離線可用，一個 HTML 檔就搞定。

線上即用：<https://cchpucky1984.github.io/storyboard-9grid/>

> 下載 `index.html` 落機，雙擊即開（Chrome / Edge / Firefox / Safari 均可）。

---

## 功能

- **拖圖片入格** — 由資料夾一次拖多張，由落點格開始依序填入
- **三種入圖入口** — 檔案拖放 / 點擊空格選檔 / `Ctrl+V` 貼上截圖
- **格內構圖調整** — 格內拖曳＝移動畫面；滾輪＝以遊標為中心縮放（1×–6×）
- **調換鏡頭順序** — 拖格左上角 `⠿` 握把到另一格即互換
- **格數** — 2×2（四格）/ 3×3（九宮格）/ 3×2（六格）/ 4×4（十六格）
- **每格比例** — 16:9、9:16、4:3、1:1、2.39:1
- **匯出 PNG** — 自訂輸出寬度 1080 / 2048 / 2560 / 3840、間距、外邊距、背景色、鏡頭序號
- **複製圖片** — 直接貼進 Word / 文件 / 聊天
- **鍵盤** — `1`–`9` 選格、`Del` 清除、`Ctrl+V` 貼上

## 為何係「格內 canvas」而唔係貼 `<img>`

每格用一個獨立 `<canvas>` 繪製，平移／縮放存成**相對於格寬的正規化比例**（`{zoom, offX, offY}`）。
螢幕預覽同匯出共用同一支 `drawCover()`，只換像素尺寸，所以永遠 WYSIWYG — 預覽點樣，匯出就點樣，唔會走位。

偏移每次都會 clamp，確保任何縮放／拖曳下都唔會露底邊。

## 匯出尺寸計算

```
gap    = outW × 間距%      pad = outW × 外邊距%
cellW  = (outW − pad×2 − gap×(cols−1)) ÷ cols
cellH  = cellW × 格高比例 ÷ 格寬比例
outH   = pad×2 + cellH×rows + gap×(rows−1)
```

間距／邊距用「輸出寬度的百分比」，所以 1080 換到 3840 都唔會比例失真。

## 已知限制

- **HEIC / RAW 讀不到** — iPhone 原相請先轉 JPG / PNG（`img.onerror` 會提示）
- **匯出位置** = 瀏覽器下載資料夾（可在瀏覽器設定「每次詢問儲存位置」）
- 切換格數時（例如 3×3 → 2×2）只會保留前面 `min(新格數, 舊格數)` 格，屬預期行為
- 「複製圖片」需瀏覽器支援 `ClipboardItem`，且必須由真實點擊觸發；失敗請改用「匯出 PNG」

## 開發

純前端單檔，無 build、無 npm。改完直接重新載入頁面即可。
測試鉤子：`window.SB = { state, buildExportCanvas, drawAll, setImageFromURL, placeFiles }`。
